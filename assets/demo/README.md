# Video files

Place exactly these seven MP4 files in this folder:

- `overview.mp4`
- `sim_pick_fruit.mp4`
- `real_pick_fruit.mp4`
- `sim_open_drawer.mp4`
- `real_open_drawer.mp4`
- `sim_close_fridge.mp4`
- `real_close_drawer.mp4`

All `<video>` elements are already wired in `index.html` with `autoplay muted loop playsinline`.
`script.js` additionally forces `muted = true` and `volume = 0`.

Recommended encoding: MP4 / H.264, web-optimized, 16:9 when possible.
